# Product Spec

## Linked Issue

GH-65

## 用户问题

用户不能在画布上直接拖端口连线或断线,只能在表单里手写 from/to。节点编辑器应支持从输出端拖到输入端创建边,并在不兼容端口上提供即时反馈。

## 目标

- 输出端口拖到兼容输入端口创建 edge 并即时成版。
- 断开已有 edge 后即时成版,可 undo 恢复。
- 拖拽中按 `PortType` 高亮兼容/不兼容端口。
- 输入端已占用时提供替换/取消选择。

## 非目标

- 不实现 edge 自动布局/折线路由美化。
- 不实现节点增删或复制粘贴。
- 不改变 graph validation 的类型规则。

## Behavior Invariants

1. 只有 output -> input 且 `PortType` 兼容时可落点创建 edge。
2. 不兼容端口在拖拽中不可落点,释放后不产生版本。
3. 创建/删除 edge 使用 GH-59 `/versions/ops` 的 `add_edge` / `remove_edge`,成功后版本历史前进。
4. 输入端已占用时,用户必须明确选择替换或取消;不得静默覆盖。
5. undo/restore 后 edge 状态与画布一致。
6. 触摸/鼠标取消拖拽时不产生 op。

## 验收标准

- [ ] 拖线连接两个兼容端口成功成版。
- [ ] 不兼容端口拖不上且无版本写入。
- [ ] 断线成版,undo 恢复该边。

## 边界情况

- 同一个端口重复连线。
- 拖拽中节点被取消选择或画布滚动。
- 后端返回 409/400。

## 发布说明

画布编辑体验新增直接连线能力。需要保持键盘/表单路径可用作为辅助方式。
