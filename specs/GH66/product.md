# Product Spec

## Linked Issue

GH-66

## 用户问题

用户不能从画布直接添加、删除或粘贴节点。添加/删除需要打开手动 proposal 表单,复制只写出文本而没有粘贴回画布的闭环。

## 目标

- 节点库面板按 catalog 分类/搜索,支持拖入或双击添加节点。
- Delete 删除所选节点及关联边,一次批量 op 原子成版。
- 复制/粘贴选区生成新 id 的节点子图,保留内部边。
- 全流程不需要打开手动 proposal 表单。

## 非目标

- 不实现自定义节点或子图打包发布。
- 不做自动布局优化。
- 不实现端口拖拽连线细节(GH-65)。

## Behavior Invariants

1. 节点库只展示 catalog 中可用节点,支持搜索和类别过滤。
2. 添加节点使用 `add_node` op,生成唯一 node id,位置来自 drop point 或当前 viewport。
3. 删除节点使用批量 op 删除节点及关联 edges,成功后一次版本前进。
4. 复制/粘贴选区时新节点 id 不与现有图冲突,内部边重映射到新 id。
5. 粘贴外部无效 clipboard 不产生版本,显示明确错误。
6. undo/restore 能完整恢复 add/delete/paste 前状态。

## 验收标准

- [ ] 从面板添加节点并跑通,不打开手动 proposal 表单。
- [ ] 删除带边节点一次成版,undo 完整恢复。
- [ ] 复制 2 节点 1 边选区后粘贴,新子图 id 不冲突且内部边正确。

## 边界情况

- catalog 为空或加载失败。
- 粘贴内容版本过旧或节点类型已不存在。
- 多选包含外部边时只保留内部边或明确提示。

## 发布说明

画布获得节点库和基础编辑闭环。需要保持键盘快捷键可发现但不依赖说明文本完成基本操作。
